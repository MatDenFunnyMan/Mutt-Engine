Put your custom sticker sets here!

Organize PNGs in folders with any name you want.

=== GLOBAL CONFIG (infoStickers.json) ===

{
  "enable_fnf_stickers": false,
  "no_stickers": false
}

enable_fnf_stickers: true = show original FNF stickers + yours | false = only yours
no_stickers: true = only transition, no stickers | false = show stickers

=== FOLDER CONFIG (stickers.json inside each folder) ===

{
  "scale": 1,
  "stickerSongs": []
}

scale: size (1 = normal, 1.5 = bigger, 0.5 = smaller)
stickerSongs: [] = all songs | ["Song Name", "song-hard"] = only those songs
